# KegeFit Pro — Entrenamiento de Suelo Pélvico y Kegel Yoga Masculino

App web progresiva (PWA) **100% gratuita y sin suscripciones** para el fortalecimiento del piso pélvico masculino, mejora de la función eréctil y control eyaculatorio, basada en evidencia científica y protocolos de Kegel Yoga somático.

## Características

- **25 Ejercicios con Tutoriales Animados en SVG**:
  - **Suelo Pélvico / Kegels**: Kegel Lento, Rápido, Super Kegel, Ascensor, Invertido, Pulsos.
  - **Fuerza y Cadena Posterior**: Puente de Glúteos, Puente Elevado, Puente Unilateral, Sentadilla Pélvica, Sentadilla Sumo, Mesa Invertida (Reverse Tabletop), Patada en Cuadrupedia (Donkey Kick), Sentadilla Jinete / Postura de la Diosa, Hipopresivos.
  - **Flexibilidad y Descompresión**: Liberación de Psoas (Knee to Chest), Mariposa Reclinada (Supta Baddha), Mariposa sentada, Balasana (Niño), Figura 4, Bebé Feliz, Piriforme.
  - **Respiración Somática**: Respiración Diafragmática, Técnica 4-7-8, Sincronización Respiración + Kegel.
- **Programa Guiado de 12 Semanas**: Progresión de 4 fases (Activación, Construcción, Intensificación, Maestría).
- **Plan de Mantenimiento Continuo (Semana 13+)**: 3 sesiones semanales rotativas (Potencia, Control, Recuperación) para mantener los resultados de por vida sin regresión muscular.
- **Timer Inteligente Guiado**: Sonidos sintetizados por Web Audio API, vibración háptica y arco circular visual sin retroceso confuso.
- **PWA Instalable**: Funciona offline en Android, iPhone y PC en pantalla completa.

## Publicación en GitHub Pages (Uso desde el Celular sin WiFi)

1. En tu cuenta de GitHub, creá un nuevo repositorio (por ejemplo, `kegelfit-pro`).
2. Conectá el repositorio local y subí el código:
   ```bash
   git add .
   git commit -m "KegeFit Pro v2.0 - 25 ejercicios y Kegel Yoga"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/kegelfit-pro.git
   git push -u origin main
   ```
3. En GitHub, andá a **Settings** -> **Pages** (en el menú lateral izquierdo).
4. En **Source**, seleccioná la rama `main` y la carpeta `/ (root)`, luego clic en **Save**.
5. ¡Listo! En 1 minuto tendrás tu enlace público HTTPS (ejemplo: `https://TU_USUARIO.github.io/kegelfit-pro/`) para abrir e instalar en tu celular desde cualquier lugar con 4G/5G.
